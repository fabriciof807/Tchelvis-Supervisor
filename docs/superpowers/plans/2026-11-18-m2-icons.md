# M2 Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 16 emoji in the Herdr mod with monochrome Lucide SVG icons tinted by the theme, installed by `tchelvis setup` and checked by `tchelvis doctor`.

**Architecture:** SVG files live in `assets/herdr-app/mods/tchelvis/icons/`, are embedded in the binary (`src/assets.rs`) and written next to the mod by setup. The mod renders them with the existing `svg(path)` primitive through one `icon()` helper and one name→path map.

**Tech Stack:** Rust (`include_str!`, existing setup/doctor code), mod JS (GPUI `svg`, `h_flex`), Node tests.

**Spec:** `docs/superpowers/specs/2026-11-18-m2-icons-design.md`

## Global Constraints

- Exactly these 16 icons, Lucide names: `house`, `search`, `brain`, `stethoscope`, `message-square`, `clipboard-list`, `folder`, `rocket`, `zap`, `triangle-alert`, `key-round`, `monitor`, `settings`, `timer`, `sparkles`, `fish`; plus `LICENSE-lucide.txt` (Lucide ISC license text).
- Source: `lucide-static@0.460.0` (`https://unpkg.com/lucide-static@0.460.0/icons/<name>.svg`; license `https://unpkg.com/lucide-static@0.460.0/LICENSE`). Files saved unmodified.
- Installed path: `~/.config/herdr-app/mods/tchelvis/icons/<name>.svg`; the mod references `"mods/tchelvis/icons/<name>.svg"` (same convention as `"mods/workspace-chrome/spinner.svg"`).
- Only emoji change; typographic symbols (● ○ ◌ ↻ ↗ → ↳ ↵ ▾ ▸ ▶ ◁ ▷ ✓ ✎ ⎇ ⌘ ⏻ ✦ ◎ ✧ ◈ ◆) stay as text.
- The alert detection at the `line.includes("⚠")` site (~main.js:7938, reads supervisor output) stays, written as `"⚠"`.
- No new crate or npm dependencies.

## Review Focus

- An icon file missing on disk (old install) → `doctor` reports `herdr_mod` as `warn` naming the icon state; setup reinstalls it. Test in Task 1.
- Icon map entry pointing to a file that does not exist in `icons/` → test fails. Test in Task 2.
- Emoji left inside template strings (e.g. `` `🔑 ${…}` ``, provider glyph returns) → scan test fails. Test in Task 2.
- `blockedChildrenBadge` text changes (no `⚠`) → fleet-tree tests updated to the new text and the badge still renders the warning icon. Task 2.
- Theme tinting: icons use `text_color` from the theme at each site, never a hard-coded color. Review in Task 2.
